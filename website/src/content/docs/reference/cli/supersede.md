Supersede an old memory with its replacement

```text
memctrl supersede [OPTIONS] <OLD_ID> <NEW_ID>
```

| Argument | Description |
| --- | --- |
| `<OLD_ID>` | The memory being replaced |
| `<NEW_ID>` | The memory that replaces it |

Every command also takes the [global options](/memctrl/reference/cli/#global-options) `--db` and `--rc`.
